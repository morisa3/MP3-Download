# EZ Audio Studio v1.10.0

整合 YouTube 單曲／播放清單下載、標籤編輯、封面裁切及內嵌、響度掃描與音訊輸出。沿用 **Python 3.12 + Flet 0.21.2**。

## 安裝與啟動（Windows）

將 ZIP 解壓到可寫入的資料夾，雙擊 `start.vbs`（不開 cmd 視窗）或 `start.bat`。第一次尚未建立 Python 環境時，`start.vbs` 會自動改開 `start.bat` 顯示安裝進度；之後就不再出現 cmd 視窗，錯誤訊息改以對話框顯示，詳細輸出寫入 `%LOCALAPPDATA%\EZAudioStudio\console.log`。第一次會建立 `%LOCALAPPDATA%\EZAudioStudio\venv-py312`，只在缺套件或 Flet 版本不符時安裝依賴；安裝成功後同一次操作直接開啟程式。之後更新程式並解壓到另一個資料夾，也共用這份 Python 環境，不必重新執行完整環境檢查。若需要詳細檢查，才手動執行 `check_environment.py`。

需安裝 Python 3.12 與 Python Launcher（`py`）。YouTube 網站可能需要 JavaScript runtime；若下載失敗且尚未安裝，可執行 `install_runtime.bat` 安裝 Deno。本包不包含 FFmpeg，請自行放入 `EZAudioStudio\ffmpeg\bin\ffmpeg.exe`。請勿直接在 ZIP 壓縮檔中執行。

## v1.10.0 bilibili 支援

網址欄可直接貼 bilibili 網址，流程（日期篩選、封面裁切、響度、輸出）與 YouTube 相同。

| 網址 | 自動模式的處理 |
| --- | --- |
| `bilibili.com/video/BV…` 單P | 單曲 |
| `bilibili.com/video/BV…` 多P（未帶 `?p=`） | 每個分P一首；標題取分P名稱，專輯名稱為影片標題 |
| `bilibili.com/video/BV…?p=3` | 只取第 3P；「整份清單」模式則取全部分P |
| `b23.tv/…` 分享短網址 | 先展開成實際網址再處理 |
| `bilibili.com/audio/au…`（音樂區） | 單曲 |
| `space.bilibili.com/<UID>/video` | UP 主全部投稿，比照 YouTube `/videos` 依發布時間編號（最舊為 1） |
| 合集、系列、收藏夾 | 照清單原順序 |

- 分享網址中的追蹤參數（`spm_id_from`、`vd_source` 等）會自動移除，同一支影片不會因參數不同被重複下載。
- 歌手欄使用 UP 主名稱，日期為投稿日期。
- **音質與登入**：未登入時 bilibili 通常只給較低音質的音訊。要較高音質，請用瀏覽器擴充功能（如 Get cookies.txt LOCALLY）匯出**已登入**的 cookies.txt，在「下載設定」指定；Hi-Res 需大會員。程式只記住檔案位置（`%LOCALAPPDATA%\EZAudioStudio\cookies_path.txt`），不把內容寫入專案。cookies.txt 等同登入憑證，請勿分享。
- 出現 412 代表 bilibili 暫時限制請求頻率，稍候按「重試失敗項目」；UP 主空間頁特別容易遇到，指定 cookies 通常可改善。
- 番劇、課程等付費內容不在支援範圍。

## v1.9.0 修正與改進

- **單曲沿用上一首資訊（修正）**：清單轉檔完自動清空後，專輯名稱、歌手、日期、共用封面不再殘留；之後貼的單曲網址也不會被套上前一份清單（第一首）的資訊與封面。共用資訊只套用到同一個清單網址的歌曲。只有一首的 OLAK 單曲清單視為單曲處理。
- **releases 封面**：`/releases` 讀取時保存卡片上的封面，下載時優先使用（Google 圖床會先要求 1200×1200 大圖），失敗才退回影片縮圖。舊版 list 快取沒有卡片封面，第一次會自動重讀 releases 頁一次（只讀目錄，不重查各首）。
- **依發行時間編號**：「下載設定 → 曲目編號」預設「自動」：頻道 `/releases`、`/videos` 頁依頁面順序（新到舊）反推，最舊為 1，新歌接在最後，舊歌曲號不變；一般播放清單照原順序。也可選最新為 1 或照來源順序。重新掃描時，清單中尚未輸出的歌曲曲號一併更新（在歌曲詳情手動改過曲號的保留）。重試仍依來源清單位置，不受重新編號影響。
- **響度一致性**：新增「校正方式」，預設「增益＋限幅」。整首只調一個固定音量；峰值會超過 True peak 時才以 4 倍取樣限幅；輸出後再量一次，偏差超過 0.5 LU 自動補正重轉一次。舊的 loudnorm 仍可選；若 loudnorm 對某首改用動態壓縮，該曲會出現警告。響度調整對話框同樣可選。
- `update_downloader.bat` 改用與 start.bat 相同的共用 Python 環境。

## v1.8.0 封面縮圖與獨立響度調整

- 中間歌曲清單顯示目前套用封面的裁切預覽，含共同封面。滑鼠移入縮圖時在該列放大至 200px，移開還原；不需開啟裁切頁即可檢查。
- 上方「清空清單」後新增「響度調整」。可處理目前勾選歌曲，或選擇資料夾匯入（可含子資料夾）。
- 對話框可設定目標 LUFS、True peak 與另存／覆蓋方式。「僅掃描響度」不更動原始音檔；「確認並調整」會掃描、校正並再次測量輸出。
- 另存為原檔名加 `_響度調整`，檔名已存在會自動編號，保留原檔。預設另存位置沿用主畫面的輸出位置。
- 覆蓋需要在對話框勾選確認；先在程式 temp 完成編碼、封面及長度驗證，再將完成檔暫存到原檔所在磁碟並替換。取消、驗證或寫入失敗時不替換原檔；成功覆蓋後不另留備份。
- 支援 MP3、M4A、FLAC、WAV、OGG、OPUS。保留格式與原始內嵌圖片，不套用共同標籤或封面裁切。會移除已失效的 ReplayGain／R128 音量標籤，以免播放器重複調整。
- MP3／AAC／OGG／OPUS 會重新編碼，不是無損音量標籤修改；無法保證原有編碼參數逐項一致。WAV 輸出為 PCM，其他格式以既有編碼／相容編碼輸出。
- 另存後中間清單仍顯示原始來源檔的響度；校正後數據在歌曲詳情的 `output_verification`，完整輸出位置見處理紀錄。覆蓋後則顯示調整後響度。
- 本次未改動原有一般輸出的封面寫入方式。EZ CD Audio Converter 封面相容性仍需用舊／新實際音檔比對，尚未定因。

## v1.7.0 掃描快取與 releases 單曲

- 「每首歌 JSON 報告」是轉檔報告，不是掃描紀錄；本版另外自動保存掃描快取，無須勾選輸出 JSON。
- 相同網址再次使用時重用清單、單曲解析與已知影片日期。改日期區間也能重用，包括上次日期範圍外的影片。
- 要找新發布或已更動的歌曲，在「下載設定」勾選「重新掃描網址與日期」，再執行下載。此選項會在本次開啟程式期間保持勾選，完成後可取消。
- 快取位於 `EZAudioStudio/list`，不隨音訊暫存清除而消失；更換程式資料夾時請一併複製 list。`lists` 保存網址清單，`releases` 保存專輯是否多首或對應影片，`videos` 保存已讀取的影片資訊及來源日期；都是 JSON，含 UTC 掃描時間。不是單一合併報表。
- 第一次仍須掃描；每筆完成即寫入。中斷時只保留已完成部分，未知日期、解析失敗會在重試時重新查詢。快取不保存音訊，實際下載仍需連網向 YouTube 取得媒體。
- `/releases` 網址在「自動」或「清單」模式皆可使用，自動只保留一首的發行項目。已知超過一首直接略過；首數未知時只讀該專輯最多前兩個清單項目，不掃各首日期、不下載音訊。一般播放清單仍正常處理全部歌曲。
- 每首單曲保留自己的專輯、日期與封面；左下共用編輯仍可手動套用。
- 日期篩選仍依影片發表／上傳日期，**不等同 releases 卡片顯示的專輯發行日期**。未取得日期時不猜測、不下載，保留重試。
- 即使有快取，網站限制、影片移除、登入要求仍可能導致實際音訊下載失敗。

## v1.6.0 新增功能

### 名稱整理

- 讀取頻道後，自動移除名稱尾端的 Channel、Official、Official Channel（含 Offical 常見拼字錯誤與大小寫變化），填入曲目歌手、專輯歌手。
- 下載設定預設勾選「下載時自動整理歌曲標題」。只移除明確的官方影片標記、其相鄰分隔線，以及與頻道歌手完全相符的標題前綴。例如 `REiNa - IGNITION (Official Music Video)` → `IGNITION`。不任意拆開不明的分隔線；Live、Remix、feat. 等資訊保留。
- 「歌曲詳情」新增「整理名稱」、「復原本次整理」、「還原來源名稱」。按鈕先修改編輯欄位，按「儲存修改」才套用，欄位仍可手動修改。
- 左下編輯資訊新增「整理歌手名稱／復原整理」。按「儲存並返回」同步清單。
- 來源名稱保存在工作資料中。舊版已載入歌曲若沒有來源紀錄，仍可整理及手改，但無法還原尚未保存過的來源。
- 單首手動改過的歌手、專輯、日期等，輸出時優先使用單首值。之後再次明確儲存左下批次資訊，會依批次非空白欄位統一覆蓋整份清單。

### 發表日期範圍

網址欄右側按「下載設定」，填入日期起、迄。

| 想取得的範圍 | 起 | 迄 |
| --- | --- | --- |
| 2026 年 9 月整月 | 2026-09 | 2026-09 |
| 9 月 10～20 日（含兩端） | 2026-09-10 | 2026-09-20 |
| 9 月 1 日以後 | 2026-09-01 | 留白 |
| 全部清單 | 留白 | 留白 |

以 YouTube 提供的發表／上傳日期篩選，不採用專輯發行日期或手動編輯日期。日期條件在下載音訊之前檢查，範圍外不下載。未限制日期時不增加逐首日期查詢。

播放清單的簡略資料經常沒有日期，因此限制日期不代表完全不用讀取其他項目的資訊：程式仍需列出清單，並在必要時逐首查詢日期。不假定清單按時間排序，也不因遇到一首較舊的歌就停止，以免漏掉後面的符合項目。無日期或讀取失敗的歌曲保留為失敗項目，未下載，可按重試；重試仍遵守原本日期條件。

日期條件只約束這次讀取／下載；不會自動移除先前已載入的歌曲。來源清單曲號保留，不重新連號。來源日期與條件保存於工作資料中；修改專輯日期不會改變篩選依據。下載設定的預設值在重新啟動後恢復不限日期。

## v1.5.2 介面調整

上方沿用原始程式的綠、淺藍、橘、紫與藍灰色按鈕，主要工具列維持單行；視窗過窄時可橫向捲動。下方資訊與輸出區等寬等高，歌曲清單自行捲動；小視窗內較長的設定內容可各自捲動，輸出按鈕固定在右下。共同資訊只切換左下區，已移除碟號與總碟數欄位，以及批次修改、還原上次工作、開啟專案、選擇 cookies.txt 按鈕。

## 主要流程

1. 貼入網址並選「自動／含清單」、「只取單曲」或「整份清單」，按「下載音訊與封面」。來源音檔與候選封面置於程式資料夾的 `EZAudioStudio\temp\<歌曲識別碼>`。清單解析失敗的曲目仍保留曲號；按該列「重試」或上方「重試失敗項目」，會依原清單曲號再解析。私人或刪除影片仍可能持續失敗。
2. 中間清單只顯示曲號、標題、當前輸入響度（LUFS）；鉛筆可改單首標籤，裁切圖示可改單首封面。清單的共用專輯名稱、歌手、日期、曲風、作曲者和封面，按左下「編輯資訊／封面」後在同一區內編輯；按「儲存並返回」回到摘要。右下輸出區與中間歌曲清單不切換，可從清單任選一張圖（例如非 MV）或選本機圖片。留空的共用欄位沿用單首資料。來源曲目裁切更新後，共用裁切也會更新。
3. 左下角可調響度校正、內嵌封面與額外 JPG／JSON。只想得到像 `REiNa-IGNITION.mp3` 這樣的單一音檔：**勾選「內嵌封面」；「另外輸出 JPG」選「不另存圖片」；JSON 不勾選**。輸出完成前會從音檔反查圖片位元組，內嵌失敗則該首不算完成。
4. 右下角選音訊格式、位元率、取樣率、輸出封面尺寸、檔名格式與輸出位置。預設是 `E:\download`，可以直接改路徑或按資料夾圖示選擇。按「檔名／預覽」可自選 `<曲目歌星>`、`<標題>`、`<專輯>`、`<號碼>`、日期等欄位與順序。
5. 如需專輯資料夾，勾選「建立 [YYMMDD] 歌手-專輯 資料夾」，在共用資訊填完整 `YYYY-MM-DD` 日期、專輯歌手、專輯名稱。例：2026-09-26 + REiNa + REVIVE IN COLOR → `E:\download\[260926] REiNa-REVIVE IN COLOR`。此選項僅適用播放清單，不勾選時直接輸出到所選位置／檔名範本的相對子資料夾。
6. 按「確認並輸出」。轉檔與封面處理暫存也統一放在 `EZAudioStudio\temp`，結束後清除。成功項目預設自動離開清單，失敗與未輸出項目留下；成功下載的暫存資料夾只在無其他待處理歌曲引用其中封面時移除，引用尚存則延後清理。若不想清單自動清理，可取消右下「音訊輸出」區的「成功轉檔後自動清理清單」勾選。

輸出 MP3、M4A、FLAC、WAV；WAV 內嵌圖片需播放軟體支援 ID3。YouTube 的上傳日期不是唱片發行日期，請視需要在共用資訊修正。沒有上傳日期時留白，不以下載日期取代。下載失敗的資料可重試；刪除、私人或無存取權的影片不會被繞過權限。

## 注意事項

- `E:\download` 不存在但 E 槽可用時會建立；E 槽不存在請先改其他位置。
- 額外 JPG／JSON 預設關閉。選「只存一張共用 Cover.jpg」時要先指定共用封面；已有不同內容的同名檔不會覆蓋。
- 程式會在 `%LOCALAPPDATA%\EZAudioStudio\session.json` 保留工作清單、共用欄位與未處理暫存路徑。此版已移除還原上次工作、開啟專案及 cookies.txt 的介面入口。輸出檔案及本機匯入的原始音檔不會因清空清單而刪除。
- 專案中的暫存檔路徑依賴原解壓資料夾；移動該資料夾後，未完成下載可能需要重試。程式目錄需要可寫入 `temp`。
- 初次響度掃描及輸出時響度驗證使用 FFmpeg loudnorm；對靜音或受峰值限制的音檔，目標 LUFS 不一定能精確達成。
- 在 Linux 測試環境驗證了程式邏輯及 Flet 0.21.2 控制項建構；Windows 桌面實際視覺與 YouTube 即時下載仍需在使用者電腦驗收。

程式碼分層：`core/youtube.py`（下載／重試）、`core/models.py`（歌曲與共用資訊）、`core/audio.py`、`core/tags.py`（輸出與封面）、`core/crop.py`、`core/naming.py`；`ui/main_view.py`、`ui/album_view.py`、`ui/crop_editor.py` 等負責介面。`bootstrap.py` 僅負責必要的套件檢查與啟動。
